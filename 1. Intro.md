# Intro to Docker

## To run a standalone docker (no bash/terminal)

``` 
docker run hello-world
```

## To run with interactive bash

```
docker run -it \
--entrypoint=bash \
    hello-world
```

## Managing Docker containers
```
docker ps -a
```

# Different base images that can be used
```
docker run -it --rm hello-world
```
```
docker run -it --rm python:3.9.16
# add -slim to get a smaller version
```
```
docker run -it --rm ubuntu
```

# Attaching volume when running Docker
```
docker run -it \
    --rm \
    -v $(pwd)/test:/app/test \
    --entrypoint=bash \
    python:3.9.16-slim
```
` Here -v $(pwd)/test:/app/test links your system's (pwd)/test to a folder in docker image called app/test`
